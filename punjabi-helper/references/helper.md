# Punjabi helper — Preferred Word Substitutions

This file maps **incorrect/anglicized Punjabi** → **preferred authentic Punjabi**.

A blank replacement means the word/phrase should be **removed entirely** from the output.

---

## HOW TO USE THIS FILE

When writing or editing Punjabi text:
1. Scan the output for any key on the left side.
2. Replace it with the value on the right side.
3. If the value is empty `""`, delete the phrase entirely.
4. Apply longest-match first (e.g. "ਇੰਟਰੈਸਟ ਰੇਟ" before "ਰੇਟ").

---

## ADDING NEW WORDS

To expand this helper, add entries at the bottom of the relevant category section in this format:
```
| ਅੰਗਰੇਜ਼ੀ/ਗਲਤ ਸ਼ਬਦ | ਸਹੀ ਪੰਜਾਬੀ ਸ਼ਬਦ |
```
Or add a new category section with a `##` heading.
